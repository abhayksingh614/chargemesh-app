## 5. Ongoing Cleanliness Guidelines

To maintain repository hygiene over time, contributors are required to:
1. Keep the root directory minimal; place new documentation under `docs/<domain>/`.
2. Do not commit temporary test outputs or scratch scripts to git.
3. Place generated visual reports or metrics in `reports/`.
4. Run `npm run typecheck && npm run test` prior to submitting pull requests.

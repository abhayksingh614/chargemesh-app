## 4. Contributor Onboarding Checklist

To enable any open-source contributor to set up and run ChargeMesh in under 15 minutes:
1. Clone repo: `git clone https://github.com/YOUR_USERNAME/chargemesh-app.git`
2. Install dependencies: `npm install`
3. Launch local PostgreSQL + Redis: `npm run docker:up`
4. Run verification suite: `npm run typecheck && npm test`
5. Launch backend: `npm run dev:backend` (API live on `http://localhost:3000`)
6. Launch admin: `npm run dev:admin` (Portal live on `http://localhost:3001`)
7. Launch mobile: `npm run start:mobile`

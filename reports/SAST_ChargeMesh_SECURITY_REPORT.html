2. Exploitability Multiplier (EM)

$$\text{EM} = 1.0 + (0.10 \times N_{\text{crit\_remote\_unauth}}) + (0.05 \times N_{\text{high\_remote\_unauth}})$$

In the baseline audit, $N_{\text{crit\_remote\_unauth}} = 2$ and $N_{\text{high\_remote\_unauth}} = 2$, producing $\text{EM}_{\text{baseline}} = 1.30$.
Post-remediation, all critical remote unauthenticated endpoints have been protected with JWT guards and OTP requirements. Only the transitive package advisory in SAST-006 carries a network DoS trigger ($N_{\text{high\_remote\_unauth}} = 1$).

$$\text{EM}_{\text{current}} = 1.0 + (0.10 \times 0) + (0.05 \times 1) = \mathbf{1.05}$$

3. Codebase Coverage Factor (CCF)

$$\text{CCF} = \frac{\text{Total Reviewed Files}}{\text{Total Discovered In-Scope Files}} = \frac{319}{319} = \mathbf{1.0 \quad (100.0\%)}$$

4. Normalized Risk Impact (NRI)

$$\text{NRI} = \min\left(100, \left(\frac{\text{WSP} \times \text{EM}}{\text{CCF}}\right) \times \left(\frac{100}{100 + \frac{\text{Total\_SLOC}}{1000}}\right)\right)$$

With $\text{Total\_SLOC} = 54,311$:
$$\frac{100}{100 + 54.311} = \frac{100}{154.311} \approx 0.6480419$$ $$\text{NRI}_{\text{current}} = (9.1 \times 1.05 / 1.0) \times 0.6480419 = 9.555 \times 0.6480419 = \mathbf{6.192 \approx 6.2}$$

5. Overall Security Score (OSS, 0–100)

$$\text{OSS}_{\text{current}} = \max(0, \text{round}(100 - \text{NRI}_{\text{current}}, 1)) = 100 - 6.2 = \mathbf{93.8 / 100}$$

Score Tier Evaluation: 93.8 / 100 falls solidly within the EXCELLENT (90.0 – 100.0) tier, compared to the baseline score of 48.9 / 100 (POOR).
